# OpenSpec Specs

本目录保存 OpenSpec 管理的长期能力规格。当前长期规格已经承接已迁移的 V1-V9 能力；active change 的 spec delta 在归档前保留于 `openspec/changes/<change-name>/specs/`，归档后再同步到对应长期规格。

当前长期规格入口包括：

- `chat-api`
- `safe-repository-file-tools`
- `agent-loop-tool-execution`
- `skill-metadata-loader`
- `harness-development-workflow`
- `repo-query-understanding-rag`
