# OpenSpec Changes

本目录只保存进行中的 OpenSpec changes。每个 change 使用 kebab-case 命名，并包含 proposal、design、tasks、
`.openspec.yaml` 和所需 spec delta。不要从本文推断当前 active change；开始或恢复阶段时运行 `openspec list`。

历史 `specs/00x-*` 已迁移并退役；长期规格入口是 `openspec/specs/`。Active change 只保存本阶段差量，
归档时由 OpenSpec 同步长期规格；阶段历史与证据保留在 `openspec/changes/archive/`。
