# Archived OpenSpec Changes

完成并归档的 OpenSpec changes 放在本目录。归档前完成适用于该风险和 scope 的验证、review 与 durable spec sync。
只更新事实所有权确实变化的 current-facing docs；不要为了仪式化同步改写 PROGRESS，也不要把 branch、HEAD、
candidate、merge/push 或 remote parity 回填到 tracked HANDOFF。实时 repository state 始终通过 Git/OpenSpec
命令和 controller final handoff 获取。
